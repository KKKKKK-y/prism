# Reproducibility

This repository is prepared for reviewer-side reproduction without including generated datasets, trained checkpoints, or experiment outputs.

## Reference Hardware

The reported Stage-5.9 numbers were produced on a local Windows workstation with:

- GPU: NVIDIA RTX 5070 Ti
- CUDA: 12.8
- PyTorch: 2.11.0+cu128
- Python: 3.10

Other CUDA builds or CPU-only runs are supported for code validation, but exact runtime and small stochastic differences may vary.

## Seed Policy

Default experiments use `seed: 42`. Evaluation episodes use deterministic seed offsets so that planners are compared on matched environments. Reviewer demo and reproduction scripts regenerate their own toy datasets from the configured seed.

## Commands

Smoke checks:

```bash
python scripts/test_env.py
python scripts/test_shapes.py --config configs/smoke.yaml
python scripts/test_planner.py --config configs/smoke.yaml
```

Reviewer demo from scratch:

```bash
python scripts/run_reviewer_demo.py --config configs/reviewer_demo.yaml
```

Full Level-A reproduction from scratch:

```bash
python scripts/run_full_reproduction.py --config configs/reproduction_level_a.yaml
```

Paper-ready Stage-6 tables and figures from available Stage-5 result files:

```bash
python scripts/run_stage6_finalize_experiments.py
```

## Expected Trend

In the hard dynamic fire benchmark, the Current-Risk Planner achieved approximately success `0.78` and collision `0.17`. PRISM-Fusion achieved approximately success `0.85` and collision `0.13`.

Exact values may vary when regenerating datasets or training new checkpoints. Checkpoints and generated datasets are intentionally not included; they are regenerated by the reproduction scripts.
